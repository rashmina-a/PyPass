## Py Pass
This is a simple python password manager that I made with no vibe coding or usage of AI

## Installation
Just clone the repo ,Create a python virtual environment if necessary and
1.Install the requirements
```bash
pip install -r requirements.txt
```
2.Run the Program 
```bash
python3 main.py
```

## Features
- Uses the **secrets** library instead of the usual **random** library to make the password unpredictable
- Copies the generated Password Automatically to the Clipboard using the Pyperclip library
